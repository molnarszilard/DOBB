# Pose Solver (Ellipsoid - Ellipse) — MATLAB Pipeline

**two-stage** for estimating camera pose from **2D ellipse detections** and **3D ellipsoid object models**.

The pipeline processes CSV exports, computes pose hypotheses for each object, selects the **best camera pose per image**, and outputs evaluation metrics and timing information.

---

# `pose_csv_to_poseRecords_minimal.m`

This script processes **CSV files containing ellipsoid and ellipse data** and computes **camera pose candidates for each object**.

## Outputs:

- per-object pose errors
- per-image timing
- a `.mat` structure (`poseRecords`) used by the second script.

## Pose Estimation Procedure

For each object in each image:

1. Read ellipsoid parameters
2. Read predicted ellipses
3. Construct camera rotation:

```
R = Rz_est * Ry * Rx
```

4. Build ellipse backprojection cone using:

```
computeBackprojCone()
```

5. Solve for camera center candidates using the method from:

> **Gaudilliere, Simon, Berger**  
> *Perspective-1-Ellipsoid: Camera Pose Estimation from One Ellipse-Ellipsoid Correspondence*

6. Apply **chirality constraint** to select the physically valid solution.

7. Compute pose errors:

- rotation error
- translation error

# `abs_pose_lse_from_poseRecords.m`

This script loads the pose hypotheses generated by the first script and **calculates the best camera pose per image**.

---

## Input

```
results/VehBuildMinimal_poseRecords_for_bestpose.mat
```

---

## Processing Steps

### 1. Split data by sequence

Sequence ID is extracted from image names:

```
09_0000000113.png
```

---

### 2. Group objects per image

For each image:

- collect all pose hypotheses
- evaluate candidate poses.

---

### 3. Direction consistency test

Objects are considered inliers if:

```
sin2(angle) ? sin2(5°)
AND
dot > 0
```

---

### 4. Solve global rotation

A polynomial is constructed from all inlier objects.

The roots determine candidate rotations around z.

---

### 5. Compute translation candidates

For each rotation solution:

1. Compute ellipsoid–cone intersection
2. Solve camera center candidates
3. Apply chirality constraint.

---

### 6. Evaluate pose quality

Each pose candidate is used to measures overlap between:

- detected ellipse
- projected ellipsoid.

The pose with **maximum mean probIoU** is selected.
